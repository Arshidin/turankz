# Применение исправления: Market Overview для МПК

## Проблема

Market Overview не отображает данные для МПК, потому что отсутствует RLS политика для доступа к таблице `batches`.

## Решение

Создана миграция и обновлен код для обеспечения доступа МПК к анонимизированным данным batches.

## Миграция

Файл: `supabase/migrations/20250120000008_add_mpk_batches_access.sql`

### Что делает миграция:

1. ✅ Создает RLS политику "MPKs can view anonymized batches"
2. ✅ Позволяет МПК видеть batches для агрегации данных
3. ✅ Примечание: приложение должно выбирать только анонимизированные поля

## Изменения в коде

### `src/hooks/useMarketData.ts`

- ✅ Добавлен импорт `useAuthContext` для определения роли пользователя
- ✅ Обновлен `useMarketBatches` для выбора разных полей в зависимости от роли:
  - **МПК**: только анонимизированные поля (без `user_id`, `batch_number`, `notes`, `mpk_interest`)
  - **Админ**: все поля
  - **Фермер**: только свои batches (обрабатывается RLS)

## Применение

### Способ 1: Через Supabase Dashboard (рекомендуется)

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **SQL Editor**
4. Скопируйте содержимое файла `supabase/migrations/20250120000008_add_mpk_batches_access.sql`
5. Вставьте в SQL Editor
6. Нажмите **Run** или **Execute**

### Способ 2: Через Supabase CLI

```bash
supabase db push
```

## Проверка после применения

После применения миграции:

1. Войдите как МПК пользователь
2. Перейдите в раздел "Market Overview"
3. Должны отображаться данные:
   - Confirmed batches
   - Soft Committed batches
   - Forecast batches
   - Supply by Region
   - Upcoming Batches

## Безопасность

- ✅ МПК видит только анонимизированные данные
- ✅ Идентифицирующие поля (`user_id`, `batch_number`, `notes`, `mpk_interest`) не передаются МПК
- ✅ RLS политика обеспечивает доступ только для МПК пользователей

## Результат

После применения:
- МПК видит агрегированные данные о предложении (supply)
- Данные анонимизированы (без идентификации фермеров)
- Market Overview отображает реальные данные из базы
