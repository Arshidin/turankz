# Применение миграции: Исправление RLS для заявок МПК

## Критическая проблема

МПК видят заявки других мясокомбинатов. Это нарушение безопасности и конфиденциальности данных.

## Миграция

Файл: `supabase/migrations/20250120000006_fix_mpk_requests_rls.sql`

## Способы применения

### Способ 1: Через Supabase Dashboard (рекомендуется)

1. Откройте [Supabase Dashboard](https://app.supabase.com)
2. Выберите ваш проект
3. Перейдите в **SQL Editor**
4. Скопируйте содержимое файла `supabase/migrations/20250120000006_fix_mpk_requests_rls.sql`
5. Вставьте в SQL Editor
6. Нажмите **Run** или **Execute**

### Способ 2: Через psql (если есть доступ к БД)

```bash
psql -h <your-db-host> -U postgres -d postgres -f supabase/migrations/20250120000006_fix_mpk_requests_rls.sql
```

### Способ 3: Через Supabase CLI (если установлен)

```bash
supabase db push
```

## Проверка после применения

После применения миграции выполните SQL скрипт из файла `verify_mpk_rls_fix.sql` для проверки.

## Что исправляет миграция

1. ✅ Удаляет старые политики с `USING (true)`
2. ✅ Создает правильные политики для админов (с `has_role()`)
3. ✅ Создает правильные политики для МПК (только свои заявки)
4. ✅ Исправляет политику для фермеров (только для агрегации)

## Результат

После применения:
- МПК видит только свои заявки
- МПК не видит заявки других МПК
- Админ видит все заявки
- Фермер видит только агрегированные данные
