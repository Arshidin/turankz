### 3. Проверьте результаты

**Запустите скрипт проверки:**
- Откройте файл: `test_migrations.sql`
- Скопируйте содержимое
- Вставьте в SQL Editor
- Нажмите **Run**
- ✅ Все проверки должны показать "✅"

**Протестируйте FSM триггеры:**
- Откройте файл: `test_fsm_triggers.sql`

### 4. Протестируйте UI

```bash
# Запустите приложение
npm run dev
```

**Проверьте:**
- [ ] Farmer может создать batch (статус = draft)
- [ ] MPK может создать request (статус = draft)
- [ ] MPK может submit draft request
- [ ] Herd Structure не виден farmer
- [ ] Market Intent не виден MPK
- [ ] Premium UI не показывает total price
- [ ] Observer видит "Pending Activation"
