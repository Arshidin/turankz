# 🚀 Быстрое применение миграции документации

## 📋 Инструкция (3 шага)

### 1. Откройте Supabase Dashboard
- Перейдите на https://app.supabase.com
- Выберите проект: **pyznqeopylcqdjsusyzj** (или ваш проект)

### 2. Откройте SQL Editor
- В левом меню → **SQL Editor**
- Нажмите **"New query"**

### 3. Скопируйте и выполните миграцию
- Откройте файл: `supabase/migrations/20250121000002_create_docs_schema.sql`
- **Скопируйте весь SQL код** (133 строки)
- Вставьте в SQL Editor
- Нажмите **"Run"** или `Cmd/Ctrl + Enter`

## ✅ Проверка результата

После выполнения проверьте:

1. **Таблицы созданы:**
   - Table Editor → `docs_pages` ✅
   - Table Editor → `docs_navigation` ✅

2. **Дефолтные данные:**
   - В `docs_pages` должно быть 3 записи
   - В `docs_navigation` должно быть 3 записи

3. **RLS политики:**
   - Authentication → Policies → должны быть созданы 5 политик

---

## ⚠️ Если возникли ошибки

- **"relation already exists"** → Таблицы уже существуют, это нормально
- **"policy already exists"** → Политики уже существуют, можно пропустить
- **"function already exists"** → Функция уже существует, это нормально

Миграция использует `IF NOT EXISTS` и `CREATE OR REPLACE`, поэтому безопасна для повторного запуска.
