# Анализ раздела "Premium Rules Engine"

## Обзор функционала

Premium Rules Engine - система управления премиальными правилами, которые награждают желаемое поведение на рынке. Состоит из 4 типов премий:
1. **Standard Compliance** - соответствие критериям ценовой сетки
2. **Reliability** - надежность фермера
3. **Predictability** - предсказуемость (раннее подтверждение)
4. **Volume Consistency** - постоянство объема поставок

---

## Выявленные проблемы

### 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

#### 1. Хардкод имени админа

**Проблема**: В `handleSave` и `handleToggleActive` используется `changed_by: 'Admin'` вместо реального имени пользователя.

**Код**:
```typescript
changed_by: 'Admin',
```

**Риск**: 
- Нет аудита реального пользователя
- Нарушение требований к аудиту
- Невозможно отследить, кто внес изменения

**Исправление**: Использовать `useAuthContext` или `useRole` для получения реального имени.

---

#### 2. Нет валидации максимального значения

**Проблема**: Можно ввести любое положительное число, нет ограничения на максимальное значение.

**Риск**:
- Некорректные значения премий
- Возможность ввода нереалистичных сумм

**Исправление**: Добавить валидацию максимального значения (например, 1000 ₸/kg).

---

#### 3. Нет подтверждения при изменении

**Проблема**: Изменение премии происходит сразу без подтверждения.

**Риск**: Случайное изменение важных значений.

**Исправление**: Добавить подтверждение для критических изменений (например, изменение более чем на 50%).

---

### 🟠 СРЕДНИЕ ПРОБЛЕМЫ

#### 4. Нет сортировки в таблице

**Проблема**: Premiums отображаются в порядке из БД (`sort_order`), нет возможности изменить порядок.

**Исправление**: Добавить сортировку по колонкам (Level, Premium Value).

---

#### 5. Нет фильтрации/поиска

**Проблема**: При большом количестве правил сложно найти нужное.

**Исправление**: Добавить поиск и фильтры.

---

#### 6. Change History не показывает тип премии

**Проблема**: В истории изменений показывается только название уровня, но не тип премии (Standard, Reliability, etc.).

**Исправление**: Добавить колонку с типом премии.

---

#### 7. Нет группировки в Change History

**Проблема**: Все изменения в одной таблице, сложно найти изменения по конкретному типу.

**Исправление**: Добавить фильтрацию по типу премии.

---

### 🟡 НИЗКИЕ ПРОБЛЕМЫ

#### 8. UX: Можно улучшить отображение критериев

**Проблема**: Критерии отображаются списком, можно улучшить визуализацию.

**Исправление**: Добавить tooltips или expandable sections.

---

#### 9. Нет визуальной индикации изменений

**Проблема**: Не видно, что было изменено недавно.

**Исправление**: Подсвечивать недавно измененные записи.

---

#### 10. Нет экспорта данных

**Проблема**: Невозможно экспортировать настройки премий.

**Исправление**: Добавить функцию экспорта в CSV/Excel.

---
