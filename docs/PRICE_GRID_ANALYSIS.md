# Анализ раздела "Справочник цен" (Price Grid)

## Обзор функционала

Справочник цен (Price Grid) - это система управления индикативными справочными ценами для рынка скота. Состоит из двух частей:
1. **Админ-панель** (`PriceGridManagement.tsx`) - управление версиями и ячейками
2. **Публичный просмотр** (`PriceGrid.tsx`) - отображение активной версии для всех пользователей

---

## Выявленные проблемы

### 🔴 КРИТИЧЕСКИЕ ПРОБЛЕМЫ

#### 1. Не деактивируется предыдущая версия при активации новой

**Проблема**: В `useActivatePriceGridVersion()` при активации новой версии не деактивируется предыдущая активная версия.

**Код**:
```typescript
.update({
  is_active: true,
  activated_by: roleName,
})
.eq('id', versionId)
```

**Риск**: 
- Может быть несколько активных версий одновременно
- Data inconsistency
- Неопределенность, какая версия должна использоваться

**Исправление**: Сначала деактивировать все версии, затем активировать выбранную.

---

#### 2. Нет валидации данных в CellEditor

**Проблема**: 
- Не проверяется, что `weight_min < weight_max`
- Не проверяется, что цены положительные
- Нет проверки на дубликаты (одинаковые комбинации критериев)

**Риск**:
- Некорректные данные в справочнике
- Ошибки при использовании цен

**Исправление**: Добавить валидацию перед сохранением.

---

### 🟠 СРЕДНИЕ ПРОБЛЕМЫ

#### 3. Неиспользуемая группировка в PriceGrid.tsx

**Проблема**: `groupedCells` объявлен, но не используется. Все cells отображаются в плоской таблице.

**Код**:
```typescript
const groupedCells = activeGrid?.cells.reduce((acc, cell) => {
  // ... группировка
}, {}) || {};
// Но затем используется activeGrid.cells.map() напрямую
```

**Исправление**: Использовать группировку для лучшей визуализации или удалить неиспользуемый код.

---

#### 4. Нет подтверждения при удалении cell

**Проблема**: Удаление cell происходит сразу без подтверждения.

**Риск**: Случайное удаление важных данных.

**Исправление**: Добавить AlertDialog для подтверждения.

---

#### 5. Нет фильтрации и поиска в таблице cells

**Проблема**: При большом количестве cells сложно найти нужную ячейку.

**Исправление**: Добавить поиск и фильтры по age category, sex, breed group.

---

#### 6. Нет сортировки в таблице cells

**Проблема**: Cells отображаются в порядке из БД, нет возможности изменить порядок.

**Исправление**: Добавить сортировку по колонкам.

---

### 🟡 НИЗКИЕ ПРОБЛЕМЫ

#### 7. Нет экспорта данных

**Проблема**: Невозможно экспортировать справочник цен в CSV/Excel.

**Исправление**: Добавить функцию экспорта.

---

#### 8. Нет массового редактирования

**Проблема**: Нужно редактировать каждую ячейку отдельно.

**Исправление**: Добавить возможность массового редактирования (например, изменение всех цен на определенный процент).

---

#### 9. UX: Можно улучшить отображение таблицы

**Проблема**: Таблица cells может быть длинной и неудобной для навигации.

**Исправление**: 
- Добавить пагинацию
- Группировать по age category и sex
- Добавить sticky headers
