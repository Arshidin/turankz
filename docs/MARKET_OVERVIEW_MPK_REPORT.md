## Выявленные проблемы

### 🔴 КРИТИЧЕСКАЯ: Отсутствовали поля для фильтрации

**Проблема**: МПК не получал поля `breed`, `gender`, `age_min`, `age_max`, `weight_min`, `weight_max`.

**Последствия**:
- ❌ Фильтрация по критериям не работала
- ❌ В UI не отображались критерии batch
- ❌ "Upcoming Batches" не показывал детали

**Исправление**: ✅ Добавлены эти поля в запрос для МПК.

---

### 🟠 ПРОБЛЕМА: Неправильная фильтрация по статусам

**Проблема**: МПК видел все статусы, включая `draft`, `forecast`, `matched`, `closed`.

**Требования**:
- МПК должен видеть только: `soft_committed`, `confirmed`
- МПК НЕ должен видеть: `draft`, `forecast`, `matched`, `closed`

**Исправление**: ✅ Добавлен фильтр `.in('status', ['soft_committed', 'confirmed'])`.

---

### 🟡 ПРОБЛЕМА: Неправильные сообщения о данных

**Проблема**: Сообщение "Displaying sample data" показывалось некорректно.

**Исправление**: ✅ Улучшена логика показа сообщений:
- Показывается только когда реально нет данных
- Добавлено сообщение о фильтрах
- Добавлено информационное сообщение

---

### 🟡 ПРОБЛЕМА: Фильтр по Grade не работал в "Supply by Region"

**Проблема**: "Supply by Region" не учитывал фильтр по grade.

**Исправление**: ✅ Добавлена переменная `filteredRegions`, которая учитывает фильтр по grade.

---

## Исправления

### 1. Обновлен запрос данных (`src/hooks/useMarketData.ts`)

**Было**:
```typescript
const fields = role === 'mpk' 
  ? 'id, heads, avg_weight, grade, region, status, target_week, delivery_period, created_at, updated_at'
  : '*';
```

**Стало**:
```typescript
if (role === 'mpk') {
  const { data, error } = await supabase
    .from('batches')
    .select('id, heads, avg_weight, grade, region, status, target_week, delivery_period, breed, gender, age_min, age_max, weight_min, weight_max, created_at, updated_at')
    .in('status', ['soft_committed', 'confirmed'])
    .order('target_week', { ascending: true });
  // ...
}
```

**Результат**:
- ✅ МПК получает поля для фильтрации и отображения
- ✅ МПК видит только релевантные статусы
