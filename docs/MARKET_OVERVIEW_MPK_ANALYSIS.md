# Анализ Market Overview для МПК

## Выявленные проблемы

### 🔴 КРИТИЧЕСКАЯ ПРОБЛЕМА 1: Отсутствуют поля для фильтрации и отображения

**Проблема**: В `useMarketBatches` для МПК не выбираются поля `breed`, `gender`, `age_min`, `age_max`, `weight_min`, `weight_max`.

**Текущий код**:
```typescript
const fields = role === 'mpk' 
  ? 'id, heads, avg_weight, grade, region, status, target_week, delivery_period, created_at, updated_at'
  : '*';
```

**Последствия**:
1. ❌ Фильтрация по критериям не работает (`batchMatchesCriteria` использует эти поля)
2. ❌ В UI не отображаются критерии batch (breed, gender, age, weight)
3. ❌ "Upcoming Batches" не показывает детали

**Исправление**: Добавить эти поля в запрос для МПК (они не идентифицируют фермера).

---

### 🟠 ПРОБЛЕМА 2: Неправильная фильтрация по статусам

**Проблема**: МПК видит все статусы, включая `draft`, `matched`, `closed`.

**Требования**:
- МПК должен видеть только: `soft_committed`, `confirmed`
- МПК НЕ должен видеть: `draft`, `forecast`, `matched`, `closed`

**Исправление**: Добавить фильтрацию по статусам в запрос.

---

### 🟡 ПРОБЛЕМА 3: Неправильное сообщение "Displaying sample data"

**Проблема**: Сообщение показывается когда `!hasData`, но это может быть:
1. Реально нет данных (фермеры не создали batches)
2. Данные есть, но не проходят фильтры
3. Данные есть, но не проходят фильтр по статусам

**Исправление**: Улучшить логику показа сообщения.

---

### 🟡 ПРОБЛЕМА 4: UX - структура данных

**Проблемы**:
1. "Supply by Region" не учитывает фильтр по grade
2. "Upcoming Batches" показывает только первые 5, но нет пагинации
3. Нет индикации, что данные анонимизированы

**Исправление**: Улучшить UX.

---

## Рекомендации по исправлению

1. ✅ Добавить поля `breed`, `gender`, `age_min`, `age_max`, `weight_min`, `weight_max` в запрос для МПК
2. ✅ Добавить фильтрацию по статусам: только `soft_committed` и `confirmed`
3. ✅ Улучшить сообщения о данных
4. ✅ Улучшить UX структуры данных
