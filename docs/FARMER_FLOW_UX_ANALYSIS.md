## 1. РЕГИСТРАЦИЯ

### Текущее состояние

**Файл:** `src/pages/auth/FarmerRegistration.tsx`

**Структура:**
- ✅ 3 шага: Данные аккаунта → Профиль хозяйства → Проверка
- ✅ Валидация на каждом шаге
- ✅ Понятные сообщения об ошибках

#### 🟠 СРЕДНЯЯ: UX регистрации

   - 5 полей одновременно
   - Можно разбить на подшаги

2. **Нет прогресс-индикатора**
   - Только "Шаг X из 3"
   - Нет визуального прогресса

3. **Нет сохранения прогресса**
   - Если пользователь закрыл браузер, данные теряются

**Структура:**
