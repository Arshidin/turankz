# Turan Standard Pool Documentation

This directory contains the production-ready documentation for the Turan Standard Pool platform.

## Structure

- `/en/` - English documentation
- `/ru/` - Russian documentation (Русская документация)

Both language versions have identical structure and content, translated appropriately.

## Hosting

Documentation is designed to be hosted at: `https://turanstandard.kz/docs`

URL structure:
- `/docs/en/...` - English pages
- `/docs/ru/...` - Russian pages

See `NAVIGATION.md` for the complete navigation structure and sidebar configuration.
