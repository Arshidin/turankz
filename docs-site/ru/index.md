# Документация Turan Standard Pool

**Добро пожаловать в документацию платформы Turan Standard Pool.**

Эта документация предоставляет полную, готовую к использованию информацию о функциональности платформы, ролях, бизнес-логике и технической архитектуре.

## О документации

Эта документация:
- **На 100% соответствует фактической реализации** - Без спекулятивных или запланированных функций
- **Двуязычная** - Доступна на английском и русском языках
- **Институционального уровня** - Подходит для аудитов, онбординга и масштабирования
- **Роле-ориентированная** - Четкие руководства для Фермеров, МПК и Администраторов
