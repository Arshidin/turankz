# Руководство для МПК

## Обзор

Это руководство предоставляет полные инструкции для МПК (мясоперерабатывающих предприятий, участников стороны спроса) на платформе Turan Standard Pool.

---

## Регистрация и активация

### Процесс регистрации

1. **Начальная регистрация**
   - Предоставьте информацию о МПК
   - Отправьте на рассмотрение

2. **Статус аккаунта: Наблюдатель**
   - Регистрация ожидает рассмотрения администратором
   - Ограниченный доступ только для чтения
   - Не может создавать заявки на пул

3. **Статус аккаунта: Активный**
   - Администратор одобряет регистрацию
   - Включены полные разрешения МПК
   - Может создавать заявки на пул и участвовать

**Примечание**: Статус аккаунта выводится из `registration_status` и `status` полей. `registration_status` ≠ `'active'` → статус аккаунта `observer`. `registration_status = 'active'` и `status = 'active'` → статус аккаунта `active`.

---

## Просмотр сопоставлений

МПК может просматривать сопоставления для своих заявок:
- **Видимо**: Объем сопоставления, дата сопоставления, целевая неделя, требуемый сорт
- **Скрыто**: Идентификатор фермера, детали партии, сопоставления других МПК
- **Доступ**: Просмотр сопоставлений для собственных заявок на пул

**Примечание**: Сопоставления анонимизированы - МПК не может видеть, какой фермер был сопоставлен с заявкой.
