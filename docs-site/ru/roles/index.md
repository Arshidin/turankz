# Модель ролей и контроль доступа

## Обзор

Платформа Turan Standard Pool работает на основе строгой модели контроля доступа на основе ролей (RBAC). Видимость данных и действия определяются ролями пользователей.

### Глобальные принципы доступа

1. **Видимость данных и действия строго основаны на ролях**
2. **Ни один пользователь не может получить доступ к внутренним элементам управления или данным управления другой роли**
3. **Все чувствительные отношения опосредованы Администратором**
4. **Идентификаторы фермеров и МПК никогда не пересекаются**

---

## Определения ролей

### Фермер

Фермеры — это участники стороны предложения, которые объявляют партии скота и отвечают на приглашения в пул.

#### Статусы аккаунта

Статус аккаунта определяет **что пользователь может делать** (разрешения). Он отделен от оценки фермера.

- **Наблюдатель** - Регистрация ожидает или находится на рассмотрении, ограниченный доступ только для чтения
- **Активный** - Полностью активирован, может создавать партии и участвовать
- **Приостановлен** - Аккаунт временно приостановлен, доступ заблокирован

**Выведение статуса аккаунта:**
- Для фермеров: Выводится из поля `grading`
  - Оценка `observer` → статус аккаунта `observer`
  - Оценка `declared_supplier` или `standard_supplier` → статус аккаунта `active`
  - Флаг `is_restricted` → статус аккаунта `suspended`
- Для МПК: Выводится из полей `registration_status` и `status`
  - `registration_status` ≠ `'active'` → статус аккаунта `observer`
  - `registration_status = 'active'` и `status = 'active'` → статус аккаунта `active`
  - `status = 'restricted'` или `'inactive'` → статус аккаунта `suspended`
- Для администраторов: Всегда `active`

**Примечание**: Статус аккаунта отделен от оценки фермера. Оценка (`observer`, `declared_supplier`, `standard_supplier`) влияет на право на премию, но статус аккаунта определяет разрешения доступа к платформе.

#### Может просматривать

| Ресурс | Доступ |
|--------|--------|
| Собственный профиль | ✅ Полный |
| Собственные партии скота | ✅ Полный |
| Собственный календарь продаж | ✅ Полный |
| Собственные снимки структуры стада | ✅ Полный |
| Собственные рыночные намерения | ✅ Полный |
| Приглашения в пул (полученные) | ✅ Ограниченный (без идентификатора МПК) |
| Агрегированные сигналы спроса | ✅ Анонимизированные (без идентификаторов МПК) |
| Справочная сетка цен | ✅ Только чтение |
| Другие фермеры | ❌ Нет |
| Идентификаторы МПК | ❌ Нет |
| Детали заявок на пул | ❌ Нет |
| Собственные сопоставления партий | ✅ Ограниченный (без идентификатора МПК) |
| Системные данные | ❌ Нет |
| Национальная структура стада | ❌ Нет (только для администратора) |

#### Может выполнять

| Действие | Разрешение | Примечания |
|----------|------------|------------|
| Объявлять новые партии | ✅ | Должен быть статус Активный |
| Изменять готовность партии | ✅ | Прогноз → Предварительно → Подтверждено |
| Подтверждать приглашения в пул | ✅ | Если Активный |
| Отклонять приглашения в пул | ✅ | Если Активный |
| Создавать снимки структуры стада | ✅ | Только индикативные |
| Создавать рыночные намерения | ✅ | Только необязательные |
| Выражать интерес | ❌ | Действие только для МПК |
| Создавать заявки на пул | ❌ | Действие только для МПК |
| Видеть идентификаторы МПК | ❌ | Никогда не раскрываются |
| Редактировать данные других фермеров | ❌ | Только собственные данные |

#### Не может делать

- Просматривать партии или профили других фермеров
- Видеть идентификаторы МПК или контактную информацию
- Получать доступ к элементам управления администратора
- Просматривать системную статистику
- Видеть сопоставления для партий других фермеров (видны только собственные сопоставления)
- Получать доступ к агрегации национальной структуры стада

### МПК (Мясоперерабатывающее предприятие)

МПК — это участники стороны спроса, которые выражают интерес и создают заявки на покупку пула.

#### Статусы аккаунта

- **Наблюдатель** - Регистрация ожидает или находится на рассмотрении
- **Активный** - Полностью активирован, может создавать заявки на пул

#### Может просматривать

| Ресурс | Доступ |
|--------|--------|
| Собственный профиль | ✅ Полный |
| Агрегированное предложение (по региону, месяцу, готовности, сорт) | ✅ Анонимизированное |
| Агрегированное рыночное намерение | ✅ Анонимизированное |
| Элементы списка наблюдения | ✅ Только собственные |
| Собственные заявки на покупку пула | ✅ Полный |
| Статус заявки и процент заполнения | ✅ Только собственные |
| Результаты сопоставления (собственные заявки) | ✅ Ограниченный (без идентификаторов фермеров) |
| Справочная сетка цен | ✅ Только чтение |
| Индивидуальные партии фермеров | ❌ Нет |
| Идентификаторы фермеров | ❌ Нет |
| Индивидуальное владение партиями | ❌ Нет |
| Данные управления администратора | ❌ Нет |
| Оценки надежности фермеров | ❌ Нет |
| Национальная структура стада | ❌ Нет (только для администратора) |

#### Может выполнять

| Действие | Разрешение | Примечания |
|----------|------------|------------|
| Выражать интерес к предложению | ✅ | Если Активный |
| Создавать заявки на пул | ✅ | Если Активный, в пределах окна сопоставления |
| Изменять собственные черновики заявок на пул | ✅ | Только статус Черновик |
| Отменять собственные заявки на пул | ✅ | До начала сопоставления |
| Подтверждать поставку | ✅ | В жизненном цикле выполнения |
| Просматривать сопоставления собственных заявок | ✅ | Может видеть сопоставления для собственных заявок на пул (анонимизированные) |
| Видеть идентификаторы фермеров | ❌ | Никогда не раскрываются |
| Видеть детали индивидуальных партий | ❌ | Только агрегированные |
| Получать доступ к элементам управления | ❌ | Только для администратора |

#### Не может делать

- Просматривать профили или партии индивидуальных фермеров
- Видеть идентификаторы фермеров или контактную информацию
- Получать доступ к элементам управления сопоставлением администратора
- Просматривать системную статистику
- Видеть заявки других МПК
- Получать доступ к данным национальной структуры стада

### Администратор (TURAN / ZENGI)

Администраторы — это центральные координаторы с полным контролем платформы.

#### Типы администраторов

- **Администратор TURAN** - Полный доступ к платформе
- **Администратор ZENGI** - Полный доступ к платформе (те же разрешения)

#### Может просматривать

| Ресурс | Доступ |
|--------|--------|
| Все профили | ✅ Полный |
| Все фермеры | ✅ Полный с идентификаторами |
| Все МПК | ✅ Полный с идентификаторами |
| Все партии | ✅ Полный с владением |
| Все заявки на пул | ✅ Полный |
| Все сопоставления пулов | ✅ Полный |
| Все выполнения | ✅ Полный |
| Оценки надежности | ✅ Полный |
| Журналы аудита | ✅ Полный |
| Данные управления | ✅ Полный |
| Национальная структура стада | ✅ Полный (агрегированная) |
| Обзор рыночных намерений | ✅ Полный |
| Окна сопоставления | ✅ Полный |
| Управление сеткой цен | ✅ Полный |
| Настройки премий | ✅ Полный |

#### Может выполнять

| Действие | Разрешение | Примечания |
|----------|------------|------------|
| Обновлять оценку фермера | ✅ | С обязательной заметкой |
| Обновлять статус МПК | ✅ | С обязательной заметкой |
| Применять/удалять ограничения доступа | ✅ | С обязательной заметкой |
| Создавать окна сопоставления | ✅ | Полный контроль |
| Предлагать сопоставления пулов | ✅ | Рабочее пространство сопоставления |
| Финализировать сопоставления пулов | ✅ | После проверки |
| Переопределять любой статус | ✅ | С обязательной заметкой |
| Управлять сеткой цен | ✅ | Создавать/активировать версии |
| Управлять настройками премий | ✅ | Настраивать премии |
| Проверять данные структуры стада | ✅ | Устанавливать уровни уверенности |
| Полный CRUD для всех сущностей | ✅ | Все таблицы |

#### Обязательные заметки

Действия администратора, которые изменяют критические данные, **ДОЛЖНЫ** включать заметку:
- Изменения оценки фермера
- Изменения статуса МПК
- Ограничения доступа
- Переопределения статуса
- Активации сетки цен

## Правила маскировки и агрегации данных

### Данные предложения, показываемые МПК

Все данные предложения, показываемые МПК:
- **Агрегированы** по региону, статусу готовности, сорту и целевой неделе
- **Анонимизированы** - без идентификаторов фермеров, контактов или номеров партий

**Пример:**
```
✅ Показано: "Северный регион: 450 голов подтверждено, 200 предварительно"
❌ Скрыто: "Ферма ABC (контакт: +7...): Партия B-2024-042, 150 голов"
```

### Данные спроса, показываемые фермеру

Все данные спроса, показываемые фермеру:
- **Агрегированы** по региону, сорту и целевой неделе
- **Анонимизированы** - без идентификаторов МПК или номеров заявок

**Пример:**
```
✅ Показано: "Спрос на сорт A в Северном регионе: 800 голов"
❌ Скрыто: "МПК XYZ запрашивает 500 голов, контакт: ..."
```

### Идентификаторы партий

| Просматривающий | Номера партий | Идентификатор фермера | Контактная информация |
|------------------|---------------|----------------------|----------------------|
| Фермер | Только собственные | Только собственный | Только собственная |
| МПК | ❌ Скрыто | ❌ Скрыто | ❌ Скрыто |
| Администратор | ✅ Все | ✅ Все | ✅ Все |

### Сигналы надежности

| Просматривающий | Надежность фермера | Процент выполнения МПК |
|-----------------|-------------------|----------------------|
| Фермер | ❌ Скрыто | ❌ Скрыто |
| МПК | ❌ Скрыто | Только собственный |
| Администратор | ✅ Все | ✅ Все |

## Реализация контроля доступа

### Принуждение на фронтенде

Разрешения проверяются с помощью хука `usePermissions()`:

```typescript
import { usePermissions } from '@/hooks/usePermissions';

function MyComponent() {
  const { canViewAllFarmers, canUpdateFarmerGrading } = usePermissions();
  
  if (!canViewAllFarmers()) {
    return <AccessDenied />;
  }
  
  // Рендеринг компонента...
}
```

### Принуждение на бэкенде (политики RLS)

Весь доступ к данным обеспечивается на уровне базы данных через Row Level Security (RLS):

- **Фермеры** могут только SELECT/INSERT/UPDATE/DELETE свои собственные партии
- **МПК** могут видеть только агрегированные данные предложения и свои собственные заявки
- **Администратор** имеет полный доступ через политики `has_role(auth.uid(), 'admin')`

### Проверки статуса аккаунта

Маршруты защищены статусом аккаунта:

- **Наблюдатель** - Ограниченный доступ только для чтения
- **Активный** - Полные разрешения роли
- **Ограниченный** - Доступ заблокирован (переопределение администратора)

## Требования к аудиту и безопасности

### Записываемые действия

Следующие действия должны быть записаны с временной меткой, исполнителем и контекстом:

| Категория действия | Конкретные действия |
|-------------------|---------------------|
| Изменения статуса | Изменения готовности партий, Обновления статуса заявок |
| Обновления оценок | Изменения уровня оценки фермера |
| Ограничения доступа | Применение/удаление ограничений фермера, Применение/удаление ограничений МПК |
| Операции с пулами | Предложения сопоставления, Одобрения сопоставления, Создание/изменение заявок |
| Переопределения администратора | Любое переопределение статуса (требует обязательной заметки) |

### Видимость журнала аудита

| Тип журнала | Фермер | МПК | Администратор |
|-------------|--------|-----|--------------|
| Собственная активность | ✅ Ограниченная | ✅ Ограниченная | ✅ Полная |
| Активность других пользователей | ❌ | ❌ | ✅ Полная |
| Системные журналы | ❌ | ❌ | ✅ Полная |

---

## Ограничения

1. ❌ Нет сложности аутентификации помимо доступа на основе ролей
2. ❌ Нет разрешений на контракты, ценообразование или финансы
3. ❌ Нет пересечения идентификаторов ролей
4. ✅ Сохранять реализацию простой и явной
5. ✅ Граница доверия и власти, а не демонстрация технической безопасности
