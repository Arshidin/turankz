# Руководство для фермеров

## Обзор

Это руководство предоставляет полные инструкции для фермеров (участников стороны предложения) на платформе Turan Standard Pool.

---

## Регистрация и активация

### Процесс регистрации

1. **Начальная регистрация**
   - Предоставьте информацию о ферме
   - Выберите регион
   - Отправьте на рассмотрение

2. **Статус аккаунта: Наблюдатель**
   - Регистрация ожидает рассмотрения администратором
   - Ограниченный доступ только для чтения
   - Не может создавать партии или участвовать в сопоставлении
   - Выводится из: `grading = 'observer'` или `grading` равно null

3. **Статус аккаунта: Активный**
   - Администратор одобряет регистрацию
   - Включены полные разрешения фермера
   - Может создавать партии и участвовать
   - Выводится из: `grading = 'declared_supplier'` или `'standard_supplier'`

**Примечание**: Статус аккаунта отделен от оценки фермера. Оценка влияет на право на премию, но статус аккаунта определяет разрешения доступа к платформе.

---

## Приглашения в пул

### Получение приглашений

Когда администратор сопоставляет вашу партию с заявкой на пул:
- Вы получаете приглашение в пул
- Приглашение показывает: объем, сорт, целевую неделю
- **Идентификатор МПК скрыт**

### Ответ на приглашения

**Подтвердить**:
- Принимает сопоставление
- Статус партии → Сопоставлено
- Переходит к выполнению

**Отклонить**:
- Отклоняет сопоставление
- Партия остается Подтверждена
- Доступна для других сопоставлений

### Просмотр сопоставлений

Вы можете просматривать сопоставления для своих партий:
- **Видимо**: Объем сопоставления, дата сопоставления, целевая неделя, требуемый сорт
- **Скрыто**: Идентификатор МПК, детали заявки, сопоставления других фермеров
- **Доступ**: Просмотр сопоставлений со страницы деталей партии

**Примечание**: Сопоставления анонимизированы - вы не можете видеть, с каким МПК была сопоставлена ваша партия.
