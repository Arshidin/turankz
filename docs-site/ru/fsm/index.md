# Машины состояний (FSM)

## Обзор

Все критические операции на платформе Turan Standard Pool следуют строгим конечным автоматам (FSM). Это обеспечивает целостность данных, предотвращает недопустимые переходы и поддерживает согласованность системы.

---

## Matching FSM

### Состояния

| Состояние | Описание | Кто может переходить |
|-----------|----------|---------------------|
| `active` | Сопоставление создано, обязательное | Администратор (создает) |
| `finalized` | Сопоставление финализировано, запись выполнения создана | Администратор |
| `cancelled` | Сопоставление отменено | Администратор |

### Разрешенные переходы

```
active → finalized
active → cancelled
```

### Правила переходов

- Сопоставления могут быть созданы только после `lock_date` окна сопоставления
- Финализация автоматически создает записи выполнения
- Расчет премии блокируется при финализации
- Невозможно вернуться из `finalized` или `cancelled`

### Кто может инициировать переходы

| Переход | Администратор |
|---------|---------------|
| Создать сопоставление (→ active) | ✅ |
| Финализировать (→ finalized) | ✅ |
| Отменить (→ cancelled) | ✅ |

### Что блокируется

**При статусе `finalized`:**
- Расчет премии заблокирован
- Запись выполнения создана автоматически
- Статус партии обновлен на `matched`
- Статус заявки обновлен (partial/fulfilled)
