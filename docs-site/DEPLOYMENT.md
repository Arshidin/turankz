# Деплой документации

Этот документ описывает процесс автоматического развертывания документации Turan Standard Pool.

## Варианты развертывания

### 1. Vercel (Рекомендуется)

**Преимущества:**
- ✅ Бесплатный план для open source
- ✅ Автоматические деплои из GitHub
- ✅ Быстрый CDN
- ✅ Простая настройка кастомных доменов
- ✅ Preview deployments для PR

**Шаги для настройки:**

1. **Установите Vercel CLI (опционально):**
```bash
npm i -g vercel
```

2. **Подключите проект к Vercel:**
   - Перейдите на [vercel.com](https://vercel.com)
   - Войдите через GitHub
   - Нажмите "Add New Project"
   - Выберите репозиторий `turankz`
   - Настройки будут автоматически подхвачены из `vercel.json`

3. **Настройки проекта в Vercel:**
   - **Framework Preset:** Other
   - **Root Directory:** `/` (корень проекта)
   - **Build Command:** `npm run docs:build` (уже в vercel.json)
   - **Output Directory:** `docs-site/.vitepress/dist` (уже в vercel.json)
   - **Install Command:** `npm install` (уже в vercel.json)

4. **Настройка кастомного домена:**
   - В настройках проекта → Domains
   - Добавьте домен: `turanstandard.kz`
   - Настройте DNS записи согласно инструкциям Vercel
   - Vercel автоматически настроит SSL сертификат

5. **Переменные окружения (если нужны):**
   - В настройках проекта → Environment Variables
   - Добавьте необходимые переменные

**После первого деплоя:**
- Каждый push в `main` будет автоматически деплоить документацию
- PR будут получать preview URLs
- Документация будет доступна на `https://turanstandard.kz/docs` (после настройки домена)

## Локальная проверка перед деплоем

Перед первым деплоем убедитесь, что сборка работает локально:

```bash
# Установите зависимости
npm install

# Соберите документацию
npm run docs:build

# Проверьте результат
ls -la docs-site/.vitepress/dist/
```

Должна быть создана директория `docs-site/.vitepress/dist/` с HTML файлами.

## Проверка после деплоя

После первого деплоя проверьте:

1. ✅ Главная страница открывается: `https://your-domain.com/docs/`
2. ✅ Английская версия работает: `https://your-domain.com/docs/`
3. ✅ Русская версия работает: `https://your-domain.com/docs/ru/`
4. ✅ Навигация работает корректно
5. ✅ Поиск работает
6. ✅ Все ссылки ведут на правильные страницы
7. ✅ Переключение языка работает

## Обновление документации

После каждого изменения в документации:

1. Закоммитьте изменения в `main` ветку
2. Push в GitHub
3. Платформа автоматически соберет и задеплоит новую версию
4. Обычно деплой занимает 1-3 минуты

## Troubleshooting

### Проблема: 404 ошибка на `/docs`

**Решение:** Проверьте, что `base: '/docs/'` установлен в `docs-site/.vitepress/config.ts`

### Проблема: Ссылки не работают

**Решение:** Убедитесь, что все внутренние ссылки используют относительные пути (без `/docs/` префикса)

### Проблема: Стили не загружаются

**Решение:** Проверьте, что `theme/index.ts` существует и правильно импортирует `custom.css`

### Проблема: Деплой падает с ошибкой

**Решение:**
1. Проверьте логи деплоя в панели управления
2. Убедитесь, что `npm install` проходит успешно
3. Проверьте, что `npm run docs:build` работает локально
